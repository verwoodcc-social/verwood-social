# Career milestones

- `baseline.csv`: career totals from CricketStatz up to the end of the 2026 season (Saturday, midweek and
  Sunday sides). `id` is the CricketStatz name; players who share a name are numbered `#1`, `#2`…
  (most matches first).
- `links.csv`: which Play-Cricket player (by Play-Cricket id) is which CricketStatz player. Rows marked
  *TO CHECK* need a person to fill in the `cricketstatz` column (an `id` from baseline.csv, or `new` for
  someone with no CricketStatz record). Until then that player's games are still counted, but no
  milestone is posted for them.
- New players who don't appear in CricketStatz start from zero automatically.

Women's Softball careers come from Play-Cricket only and don't use these files.
